# Тестирование новой функциональности «Яндекс Маршруты» (каршеринг) 

## Цель работы
Необходимо протестировать приложение «Яндекс Маршруты» с новой функциональностью — сервисом каршеринга.  
Провести проверку вёрстки и логики работы элементов формы бронирования и навигационной карты. 

### Задачи:
- Анализ требований и подготовка тестовой документации.
- Проведение **кроссбраузерного тестирования** вёрстки:  
-- Яндекс Браузер (разрешение 800×600)  
-- Firefox (разрешение 1920×1080)  
- Тестирование логики работы окон «Способ оплаты» и «Добавление карты», а также кнопки «Забронировать».
- Оформление баг-репортов после тестирования.
